# Weather App

A beautiful weather application that displays current weather conditions and 5-day forecast for any city worldwide.

## Features

- 🔍 Search for weather by city name with autocomplete suggestions
- 📍 Get weather for your current location (geolocation)
- 🌡️ Toggle between Celsius and Fahrenheit
- 📊 5-day weather forecast
- 💾 Search history stored in localStorage (can be cleared)
- 🎨 Beautiful glass-morphism UI design
- 📱 Fully responsive layout
- ☀️ UV index with color coding
- 🌡️ "Feels like" temperature
- 💡 Smart tips based on weather conditions (umbrella, sunglasses, jacket, running, photos, windows)
- ⚡ Skeleton loader animation while loading
- ⌨️ Keyboard navigation for search suggestions (arrow keys + Enter)

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Glass-morphism, Animations)
- JavaScript (ES6+)
- Open-Meteo Weather API (no registration required)
- Font Awesome Icons
